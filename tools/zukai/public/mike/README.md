ミケの画像。`<表情>_open.png`（口を開けた）と `<表情>_close.png`（口を閉じた）の組で置く（片方だけ・`<表情>.png` だけでも動く。その場合は口が動かない）。
シーンJSONの `mike` には表情名を書く。画像は透過PNGで、余白を切り落としておく（右下の幅360×高さ400の枠に収めて表示する）。

毎日の生成では、PCの _pc/design の catkit.py と cat/*.png から、catkit が口パクに使っている2枚（口開き・口閉じ）を表情ごとにここへ書き出してから使う。
detective / talk は、既存の解説ショートの映像から切り出した暫定版（元画像が使えないときの予備）。
